
# 🍔 FoodieHub – Online Food Ordering System

FoodieHub is a beginner-friendly online food ordering website inspired by Swiggy and Zomato.

## 🚀 Features

- Responsive homepage
- Food categories
- Food search functionality
- Add to cart
- Increase and decrease food quantity
- Automatic bill calculation
- Checkout system
- Order confirmation
- LocalStorage integration

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## 📂 Project Structure

```text
FoodieHub/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Enjoy ordering food!
